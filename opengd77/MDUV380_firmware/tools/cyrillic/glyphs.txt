# Cyrillic glyphs for the radio fonts, drawn by hand to match the Latin ones.
#
# Format:   == <font> <letter>     then one line per pixel row, '#' = on.
#   font6   6x8 cell, 5x7 letters: capitals rows 0-6, small letters rows 2-6,
#           descenders row 7. Columns 0-4, column 5 is the gap.
#   font8   8x8 cell: same rows as font6, columns 0-6.
#   font16  8x16 cell: capitals rows 2-12, small letters rows 5-12,
#           descenders rows 13-15, accents rows 0-4. Columns 0-6.
# Rows not given are blank. A row shorter than the cell is padded with '.'.
# A glyph may start at a later row with "@<row>" on its first line.
#
# Letters that look exactly like Latin ones (A B E K M H O P C T X, a e o p c y x,
# and Ё/ё = Ë/ë) are not drawn here: genCyrillic.py copies them from the Latin
# glyphs of the same font, so they stay identical.
